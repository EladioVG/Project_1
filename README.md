Objetivo del Proyecto\
Identificar cuál de los planes prepago (Surf o Ultimate) genera mayores ingresos para optimizar decisiones de negocio
y presupuesto publicitario.\

Contexto de Negocio\
Se analizó una muestra de 500 clientes considerando uso de llamadas, SMS, consumo de datos, plan contratado y
comportamiento mensual durante 2018.\
Stack Tecnológico
Python, Pandas, NumPy, SciPy, Matplotlib y análisis estadístico exploratorio.
Proceso de Trabajo\
• Carga y validación de datasets\
• Revisión de tipos de datos\
• Búsqueda de inconsistencias y duplicados\
• Limpieza y enriquecimiento de datos\
• Cálculo de consumo e ingresos por cliente\
• Comparación entre planes y análisis estadístico\

Datasets utilizados\
megaline_calls.csv\
megaline_internet.csv\
megaline_messages.csv\
megaline_plans.csv\
megaline_users.csv\

Preguntas de negocio respondidas\
• ¿Qué plan genera más ingresos?\
• ¿Cómo se comportan los usuarios de cada plan?\
• ¿Existen diferencias significativas entre perfiles de consumo?\
• ¿Cómo afecta el uso excedente al ingreso final?\
Competencias demostradas\
Data Cleaning • EDA • Data Wrangling • Estadística • Visualización • Pensamiento analítico • Lógica de negocio
